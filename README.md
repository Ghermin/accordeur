# Accordeur

Accordeur de guitare simple et fluide, directement dans le navigateur.

**▶ [Ouvrir l'accordeur](https://ghermin.github.io/accordeur/)**

- Détection automatique de la corde jouée (ou verrouillage sur une corde)
- Accordages : Standard, Drop D, demi-ton / un ton plus bas, Drop C, DADGAD, Open G, Open D, Open E
- Choix du micro quand plusieurs sont branchés
- Tout se passe localement : rien n'est enregistré ni envoyé

Un seul fichier (`index.html`), sans dépendance. Pour le lancer en local :

```bash
python -m http.server 5173
```
